# Claude Code Analytics — Product Overview

An analysis tool for Claude Code that automatically captures,
archives, and analyzes your AI development conversations, so your
work with Claude Code becomes a searchable, analyzable record.

## Who it's for

Developers who use Claude Code daily and want visibility into what
they've worked on, what's running right now, and what their AI
collaboration actually looks like over time.

## What you can do

- **Automatic capture**: every conversation is saved when you exit
  Claude Code; new sessions are imported in real time as you work.
- **Dashboard**: activity at a glance — projects, sessions,
  messages, and usage over time.
- **Active Sessions**: see which Claude Code sessions are running
  right now, across all your terminals, and jump into any of them.
- **Browse sessions**: full conversation transcripts for every
  past session, organized by project.
- **Search & discovery**: search across all your conversations;
  find sessions similar to the one you're looking at.
- **Bookmarks**: save important messages with notes for later.
- **AI-powered insights**: run analyses over your sessions (e.g.
  extract the key decisions made).
- **Command palette and dark mode** for fast navigation.
